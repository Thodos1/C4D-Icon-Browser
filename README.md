Got tired of browsing Cinema 4D's icons through the Shift + F12 menu, especially when setting up User Data or changing object icons to make scenes a bit more organised.

So I made a simple icon browser that puts everything in one place, with larger previews and easy access to the icon IDs.
# Features

- Browse icons registered in the current C4D session, including third-party plugins

- Search by name or ID

- Filter icons by category

- Adjust icon preview sizes

- Click to copy an icon ID

- Drag and drop icons

- Drop an object into the browser to find its icon ID

# Installation

-  [DOWNLOAD](https://github.com/Thodos1/C4D-Icon-Browser/releases/download/release_100/IconBrowser.zip) LATEST
-  Unpack into "%APPDATA%\Maxon\Maxon Cinema 4D 202X_XXXXX\library\scripts
-  Run through Script Manager or find Icon Browser through Commander(Shift + C)

# Notes

The browser uses icons registered in your current Cinema 4D session, so the available icons will depend on your C4D version and installed plugins.

Keep in mind that third-party icon IDs might not be available on other machines.
